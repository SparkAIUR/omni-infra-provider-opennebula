# Provider core

The provider core owns the Omni-facing orchestration logic.

## Purpose

`internal/pkg/provider/` translates Omni requests into validated, deterministic OpenNebula operations.

## Key files

- `internal/pkg/provider/data.go`
- `internal/pkg/provider/validation.go`
- `internal/pkg/provider/naming.go`
- `internal/pkg/provider/hostname.go`
- `internal/pkg/provider/render.go`
- `internal/pkg/provider/provision.go`
- `internal/pkg/provider/deprovision.go`
- `internal/pkg/provider/state.go`

## Contracts

- Canonical VM names and Talos hostnames are derived from the Omni request ID.
- The provider renders Talos-compatible OpenNebula `CONTEXT`, including `SET_HOSTNAME` and manual-network `ETH*_` values when requested.
- Omni-generated schematic and kernel args carry the join path used by the validated flow.
- Logs must never expose raw auth values or sensitive rendered template fields.

## Change notes

This module is where public schema changes, retry behavior, and state schema changes usually land together. If you modify the request contract here, also update:

- [/api/provider-data](/api/provider-data)
- [/examples/machineclass](/examples/machineclass)
- `cmd/omni-infra-provider-opennebula/data/schema.json`
