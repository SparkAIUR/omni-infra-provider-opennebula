# Provider data

`providerData` is the machine-class payload that Omni passes to the OpenNebula provider for each provision request.

## Supported schema versions

```yaml
schemaVersion: v1alpha1
```

```yaml
schemaVersion: v1alpha2
```

`v1alpha1` remains supported for compatibility. `v1alpha2` adds image policy, placement, storage-aware host selection, additional disks, network profiles, per-network mode/model hints, and request-level delete behavior.

## Supported fields

```yaml
schemaVersion: v1alpha2
flavor: small
resources:
  cpu: "4"
  vcpu: 4
  memoryMiB: 8192
  rootDiskGiB: 40
templateName: talos-omni-base
datastore: ssd-primary
networks:
  - profile: talos-prod
    model: e1000
    mode: auto
networkContextMode: auto
staticNetwork:
  - name: eth0
    mac: "02:00:00:00:00:10"
    ip: 10.0.10.25
    gateway: 10.0.10.1
    dns:
      - 10.0.10.53
rootDiskGiB: 80
firmware:
  mode: uefi
  secureBoot: true
graphics:
  enabled: false
imagePolicy:
  mode: reuse-or-import
placement:
  host: compute-01
  cluster: cluster-a
  vmGroup: control-plane
  storageProfile: ceph-rbd
  requiredHostTags:
    - ceph-rbd
  excludedHostTags:
    - frontend
  networkZone: staging
additionalDisks:
  - name: state
    sizeGiB: 20
    format: qcow2
lifecycle:
  deleteMode: terminate
tags:
  role: worker
gpu:
  enabled: true
  count: 1
```

## Validation rules

- `schemaVersion` must be `v1alpha1` or `v1alpha2`.
- `v1alpha1` rejects `v1alpha2`-only fields.
- Set either `flavor` or `resources`, not both.
- `networkContextMode` must be `auto` or `manual`.
- At least one entry in `networks` is required.
- `manual` networking requires `staticNetwork`.
- `imagePolicy.mode` supports `reuse-only` and `reuse-or-import`.
- `placement` and `additionalDisks` are policy-gated by the provider runtime config.
- `placement.storageProfile` supports `any`, `local-root`, `ceph-rbd`, and `cephfs-capable`.
- `placement.requiredHostTags` and `placement.excludedHostTags` let operators target runtime-tagged hosts safely.
- `placement.networkZone` must match a zone defined in runtime config.
- `lifecycle.deleteMode` supports `terminate` and `hard`. `normal` is accepted as a compatibility alias.
- `gpu` remains schema-visible but is rejected unless the feature flag enables it.
- Hostname is derived from the Omni request ID and is not user-configurable.

## Networking behavior

### `auto`

The provider renders:

```text
NETWORK = "YES"
```

### `manual`

The provider renders:

```text
NETWORK = "NO"
ETH0_IP = "..."
ETH0_GATEWAY = "..."
ETH0_DNS = "..."
```

## Image behavior

- `reuse-only` means the provider must find an existing Talos image in OpenNebula.
- `reuse-or-import` allows the provider to import a missing Talos image when runtime config enables import and provides artifact/checksum URLs.
- Imported image ID, source URL, and checksum are persisted in provider state.

## Placement behavior

- `storageProfile: local-root` prefers non-Ceph root-disk placement.
- `storageProfile: ceph-rbd` requires a Ceph RBD-compatible datastore plus a host tagged for that path.
- `storageProfile: cephfs-capable` requires a CephFS-capable datastore plus a host tagged for that path.
- Host tags and network zones are runtime-provider concerns; they are not discovered from Omni machine classes alone.
