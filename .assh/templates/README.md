# Templates

- `provider-config.yaml.tmpl`: environment-driven provider runtime config template
- `machineclass.yaml.tmpl`: minimal OpenNebula machine-class template
- `production-ceph-storage.env.example`: example operator config for the production Ceph setup workflow
- `datastore-ceph-images.tmpl`: Ceph-backed image datastore template
- `datastore-ceph-system.tmpl`: Ceph-backed system datastore template
- `datastore-one-csi.tmpl`: Ceph RBD datastore template for CSI block volumes
- `datastore-one-csi-cephfs.tmpl`: CephFS-backed FILE datastore template for CSI shared volumes
